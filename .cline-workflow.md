# Cline Workflow Instructions

For every change made to this project:

1. **Version Bump**: Always increment the patch version (x.x.Y) in `app/build.gradle`
2. **Branch Creation**: Create a new branch with descriptive name: `feature/description` or `fix/description`
3. **Commit**: Commit changes to the new branch with clear commit message
4. **Build**: Generate debug APK using `./gradlew assembleDebug`
5. **Pull Request**: Create pull request on GitHub with descriptive title and description

## Commands to run for each change:
```bash
# 1. Check current branch and create new one
git checkout -b fix/credits-contrast-eink

# 2. Update version in app/build.gradle (patch bump)

# 3. Commit changes
git add .
git commit -m "fix: improve credits section contrast for eink devices

- Remove colored links for better eink readability
- Increase text contrast by using onSurface colors
- Change background to surface for better contrast
- Increase text size from bodySmall to bodyMedium"

# 4. Build debug APK
./gradlew assembleDebug

# 5. Push and create PR
git push origin fix/credits-contrast-eink
```

## Version Location:
File: `app/build.gradle`
Look for: `versionName "X.Y.Z"` - increment Z for patch releases
